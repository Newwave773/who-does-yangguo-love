## 数据说明

- **来源**：知乎网页版 API（登录态），四个问题下全部公开回答，横截面快照
- **规模**：1493 条回答、140,471 个赞、1137 位独立作者
- **分类**：三分类编码（A 小龙女派 / B 郭芙派 / C 其他），逐条判定 + 程序化校验，覆盖率 100%；口径与判定规则见论文 3.2 节
- **字段**：回答 ID、问题名、作者、正文全文、点赞数、评论数、创建时间、立场分类、判定理由
- **清洗说明**：按发布要求，数据中不保留问题编号（以问题名标识）；`answer_id` 保留，供核查分类时定位回答使用
- **使用限制**：数据仅用于学术研究与非商业讨论；文本版权归原作者所有；如权利人有异议请联系删除

## 方法摘要

内容分析（三分类编码）+ 描述统计 + 非参数推断检验（Mann-Whitney U / 卡方 / Kruskal-Wallis，效应量并报）+ Wilson 区间与 bootstrap + 时间序列分析 + 文本挖掘（jieba 分词、加权 log-odds 特异词）+ 集中度分析（Gini / Lorenz）+ 文本细读。定量设置与全部指标见论文第三章与 `data/analysis_metrics.json`。

## 如何使用

- **快速看数据**：浏览器打开 `viewer/index.html`（单文件、无需联网；如需在线访问可开启 GitHub Pages，将 Pages 源指向 `viewer/` 目录或根目录）
- **读理论分析**：`docs/研究论文.md`（四层模型、两派论点的文本/心理/社会/哲学分析、与全球及华语官配战争的比较）
- **查数据明细**：`data/all_answers_classified.csv` 用 Excel/WPS 打开，按 `category` 列筛选 A/B/C
- **复核统计**：`data/analysis_metrics.json` 含论文与报告中全部数字的机器可读版本
